▶ ⚙ Matching Rules — how MIDP entries are matched against ACC file names

"Smart" matching (extension ignored) is on by default because MIDP registers usually list document numbers without a file extension. Turn on the suffix rule only if your ACC files carry a revision code (e.g. "-P01") that the MIDP number doesn't include — edit the pattern to match your project's suitability coding.
